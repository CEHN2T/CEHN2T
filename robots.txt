# CEHN2T — robots.txt
# Objectif : SEO ouvert + accès aux principaux crawlers IA occidentaux
#            + blocage explicite de plusieurs crawlers non occidentaux connus.

# Limite importante :
# robots.txt fonctionne par nom de crawler (User-agent), pas par nationalité
# ou pays d'origine. Les robots non identifiés, nouveaux ou malveillants
# peuvent ignorer ces règles. Pour un blocage géographique strict, utiliser
# aussi les règles Cloudflare/WAF.
